# FILMX — كيف تفرّق حماية PPF الأصلية من المغشوشة

موشن جرافيك تعليمي 2D بطابع ورقي كلاسيكي قديم، عمودي 9:16 (1080×1920 · 30fps · 39 ثانية)،
ينتهي بـ CTA لمتجر **FILMX / فيلم إكس** للعناية بالسيارات الفاخرة.

**الملف النهائي:** `out/FILMX_PPF_Original_vs_Fake.mp4`

## الهوية الموحّدة
- **الشخصية:** أخصائية حماية سعودية (طرحة بيج جملي، عباية سوداء بأكمام مرفوعة، ساعة وخاتم ذهبي).
  نفس الوجه في كل لقطات الفيديو (Higgsfield Element `FILMX-PPF-Specialist`) + نسخة نقش حبر كلاسيكي
  (بورتريه الراوية في زاوية كل اختبار + رسمة الفهرس) + صوتها هو صوت الراوية.
- **الألوان:** من هوية FILMX — عاجي/كريمي، حبر `#1C1B18`، ذهبي `#8A6E3F` / `#C9A86A`،
  + حبر أحمر عتيق `#7A2E24` لأختام "مغشوش" فقط.
- **الخطوط:** IBM Plex Sans Arabic (هوية FILMX)، Aref Ruqaa للعناوين، Amiri للأرقام، Special Elite للآلة الكاتبة.

## التقنية
- `engine/engine.js` — محرك موشن جرافيك Canvas حتمي (frame-accurate): صور مطبوعة للفيديو، أختام،
  شمع، عدسة مكبرة بتكبير حي للفيديو، كتابة حبر، تمزق ورق، بقعة حبر، اهتزاز كاميرا، غبار وحبيبات فيلم.
- `engine/render.mjs` — Playwright + Chromium يلتقط كل فريم ويمرّره لـ ffmpeg.
- `tools/vo_process.py` — تقليص الوقفات + rubberband ×1.15 + تطبيع الصوت.
- `tools/audio_mix.py` — مؤثرات صوتية مولّدة إجرائيًا (ورق، أختام، آلة كاتبة، حبر…) + موسيقى
  بيتزيكاتو كلاسيكية (Karplus-Strong) مع ducking تحت الصوت + أصوات اللقطات الأصلية.

```bash
npm install && pip install numpy scipy pillow
./tools/build.sh                         # يبني كل شيء إلى out/
node engine/render.mjs --stills 3.9,11.6 # فريمات للمراجعة
```
